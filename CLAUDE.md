# Papeterie Démo

Projet de démonstration CodeCodeCoders (Next.js 16, TypeScript, App Router).

- Boutique fictive : rien n'est vendu, envoyé ni stocké.
- Avant de proposer un commit : `npm run typecheck`, `npm run lint`, `npm test`.
- Pour toute relecture de diff, suivre la skill `.claude/skills/review-front/SKILL.md` et le fichier `RISK.md`.
- Accessibilité : `<button>` et `<a href>` uniquement pour les éléments interactifs, un `<label>` par champ.
